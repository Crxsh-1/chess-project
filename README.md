# Chess Project

A React and TypeScript chess web application powered by Vite.

## Getting started

Install the project dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Vite will print the local URL in the terminal. Open that URL in your browser.

## Other commands

```bash
npm run build
npm test
```

Milestone 1 includes a local chess game with legal move validation, captures,
check and game-over status, reset support, and move history.
